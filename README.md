# HTML and CSS Projects

This repository contains projects and exercises I completed during my Software and Web Development studies at the Academy of Learning Career College.

## Projects

### Academy Cinemas
A cinema website built using HTML, CSS, and Bootstrap. It includes navigation, movie posters and descriptions, showtimes, ticket selections, a contact form, and a footer.

### Auto Paint Knowledge Website
A one-page website about automotive painting. It includes navigation links, an image gallery, a video section, and a contact form styled with CSS.

### Creating CSS Effects
Exercises exploring CSS styling, fonts, hover effects, layouts, and rollover menus.

### Introduction to Bootstrap
Practice using Bootstrap to create and style webpage layouts and components.

### Simple Recipes
A recipe website with food categories, images, navigation, a dropdown menu, and an About section.

### Basic HTML and CSS Exercises
Practice creating webpages with headings, paragraphs, links, images, lists, and tables, and applying styles through CSS.

### Basic HTML and JavaScript
Introductory exercises connecting JavaScript to HTML and displaying a browser alert.

## Skills Practiced

- HTML page structure
- CSS styling and hover effects
- Bootstrap components and layouts
- Navigation links and forms
- Images and embedded videos
- Git and GitHub version control
